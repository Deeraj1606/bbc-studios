# Contributing Guidelines

Thank you for considering contributing to this project! Please follow these steps:

1. **Fork the repository** and clone your fork locally.
2. **Create a feature branch**: `git checkout -b feature/your-feature-name`.
3. **Write code** adhering to the project's coding style (Kotlin formatting for Android, Prettier/ESLint for JS/TS, etc.).
4. **Add tests** where applicable.
5. **Run the CI locally** (`./gradlew test` for Android, `npm run lint && npm run build` for Node projects) to ensure everything passes.
6. **Commit with clear messages**.
7. **Open a Pull Request** targeting the `main` branch. Include a concise description of the change and reference any related issues.
